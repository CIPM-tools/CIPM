# Data for State-based Model Comparison

This folder contains data for an SSP paper. The following files / folders contain the following data:
* `raw-data/` contains the raw data with all measurements. In particular, `ms3.csv` contains the data presented in the paper.
* `analysis-scripts/` contains the R scripts for the data analysis.
* `plots/` contains generated plots for every single measurement series.
* `eval-results.json` contains (raw) analysis results.
* `all-groups.pdf` contains the plot from the paper with all groups.
